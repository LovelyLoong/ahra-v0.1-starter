# AWKP v0.1 Starter

这是 **Agent Workflow Knowledge Profile（AWKP）v0.1** 的最小参考模板。

> AWKP 是建议稿，不是 Google、A2A 或 Linux Foundation 的官方标准。

## 使用

1. 阅读 `SPEC.md`。
2. 把根 `AGENTS.md` 改成项目地图，不要写成长篇百科。
3. 在 `WORKFLOW.md` 明确状态权威、调度、租约、验证和人工门禁。
4. 复制 `work/tasks/TASK-0001/` 创建任务。
5. 运行：

```bash
python3 scripts/lint_awkp.py
```

CI 示例见 `.github/workflows/awkp-lint.yml`。
